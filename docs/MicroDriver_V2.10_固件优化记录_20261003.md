## 2. 本版主要改动

### 2.1 过流与故障保护架构

1. 软件电流环最大参考限幅调整为 `1400 mA`。
2. 软件取消旧的相电流峰值逐拍跳闸。
3. 硬件过流保护门限保持 `2500 mA`，由 DRV8376H OCP 触发。
4. nFAULT 由主循环轮询：
   - 轮询周期 `1 ms`。
   - 连续低电平确认 `1 ms`。
   - 最坏响应约 `2 ms`。
5. 确认故障后立即关闭 PWM，并将 nSLEEP 拉低。
6. 母线低于 `9.0 V` 时，nFAULT 低电平按 DRV UVLO 处理，不误判为过流。
7. 清错后故障冷却时间为 `4 ms`。
8. 速度失控保护阈值 `22000 rpm`，连续 3 个 3 kHz 周期确认。
9. 错误码区分：
   - `3`：nFAULT 硬件故障，包含过流、过温等。
   - `4`：项目扩展，外环速度失控。

### 2.2 状态机和清错

1. 修复启动时故障计数被清零导致“刚清错又报故障”的误判。
2. 只有故障计数增加才锁存新故障。
3. `FAULT_OVER` 冷却结束后可自动回到 `IDLE`。
4. 上位机下使能也可以作为故障确认入口。
5. 新增协议清错服务 `0xF1 0x12`。
6. Status1 的故障状态同时覆盖 nFAULT 和软件状态机故障。

### 2.3 首次使能零位对齐

1. 上电不再自动做 D 轴吸合对齐。
2. 上位机第一次使能时，如果零位尚未建立，固件自动执行对齐。
3. FS1320 当前对齐参数：
   - 电流 `250 mA`。
   - 时长 `1200 ms`。
4. 对齐完成后自动继续原位置或速度目标。
5. 该流程覆盖“MCU 先上电、母线后上电”的现场顺序。

### 2.4 位置模式

1. 进入位置模式时先锁存当前反馈位置，不再把目标强制设为对齐零点。
2. 从速度模式切换回位置模式时，电机会在当前位置接管，不再长距离回撤。
3. 位置环默认参数：
   - `Kp = 0.20 rpm/count`
   - `Kd = 0.00`
4. 位置轨迹：
   - 最高速度 `18000 rpm`
   - 加速度 `60000 rpm/s`
5. 位置模式旁路速度模式给定斜坡，直接使用轨迹加速度前馈。
6. 新增位置环 Kd 在线整定入口：

```text
foc gpos <kp> [kd]
```

7. 实测 `Kd=0.2` 会在停位阶段产生约 ±20 count 的粘滑极限环，因此默认改为 `Kd=0`。
8. `Kp=0.4` 对照测试同样出现约 ±10～15 count 的往复振荡，因此默认保持 `Kp=0.2`。

### 2.5 速度模式

1. 速度给定满量程恢复为 `18000 rpm`。
2. 速度环保持 3 kHz。
3. 电流环最大输出限幅调整为 `1400 mA`。
4. 速度给定斜坡保持 `20000 rpm/s`。
5. 速度失控时优先区分 nFAULT 硬件故障和真实外环失速。

### 2.6 协议和上位机接口

1. 默认串口参数为 `460800 8N1`。
2. 默认 Node ID 为 `1`。
3. `0x6073[00]` Max Iq 固定上报 `1400 mA`。
4. `0x607F[00]` Max Speed 固定上报 `18000 rpm`。
5. Control1 的 TargetIq 上限同步为 `1400 mA`。
6. 新增项目扩展错误码 `4`。
7. 新增项目扩展 DID：
   - `0x2010`：三相电流绝对值。
   - `0x2015`：编码器累计和 Z 计数。
8. 新增 `0xF1 0x12` 清错。
9. 重新整理并输出协议 V1.4 项目文档。

### 2.7 诊断能力

1. `foc step` 速度、位置、力矩模式统一按记录窗口抽稀。
2. 修复速度模式只能看到最后约 170 ms 的问题。
3. 每次打印限制为 90 行，避免 8 KB RAM 日志环覆盖启动段。
4. `foc stat` 增加位置环 Kd 显示。
5. 协议自测仍覆盖 CRC、MID 字节序、DID、状态码和扩展 DID。

### 2.8 功能样机安全项（2026-10-03 延续）

1. Control1 / `0xF1` 控制帧超时保护，默认 `200 ms`。
2. 新增 `0xF1 0x13` 正常停车：先减速到零，再下使能。
3. 新增 `0xF1 0x14` 快速停车：立即下使能。
4. 新增 `0xF1 0x15` 急停：立即下使能并锁存，必须清错后恢复。
5. 新增位置软限位和超时参数 DID `0x2020`。
6. 新增安全状态 DID `0x2021`，包含状态机、状态标志、固件/协议版本和故障快照。
7. 保护停机时记录故障码、时间、母线、转速、Iq 给定和位置。

## 3. 实机验证

### 3.1 速度控制

| 项目 | 结果 |
|---|---|
| 目标 | `18000 rpm` |
| 稳态范围 | 约 `17976..18043 rpm` |
| 保护 | 未触发速度失控或 nFAULT |
| 稳态 vq | 约 `6.7 V` |
| 母线 | 约 `12.3 V` |

结论：空载台架已经能够稳定运行到 18000 rpm。当前 vq 已接近
12 V 母线下的线性调制边界，电压动态余量有限。

### 3.2 位置控制

| 项目 | 结果 |
|---|---|
| 位移 | `1.586` 圈，即 `6489` 计 |
| 到达时间 | 约 `72 ms` |
| 500 ms 末端误差 | 约 `+1 count` |
| 末端持续振荡 | 未观察到 |
| 默认参数 | `Kp=0.20`，`Kd=0` |

结论：位置模式启动慢和停位极限环问题已明显改善。

### 3.3 协议入口位置控制

通过 `proto feed` 注入 Control1 位置帧：

| 项目 | 结果 |
|---|---|
| 目标位置 | `7150` 计 |
| 最终反馈 | `7155` 计 |
| 最终误差 | `-5` 计 |
| 到位标志 | 已到位 |
| 控制拍率 | 约 `59.4 kHz` |

协议入口和本地调试入口使用同一套位置控制逻辑。

## 5. 当前限制

1. 18000 rpm 结论来自空载、12 V 母线台架，尚未覆盖长期温升和真实负载。
2. 18000 rpm 时 vq 已约 `6.7 V`，接近 12 V 母线的调制边界。
3. 位置控制验证以小行程、空载为主，带载定位和大范围轨迹尚未验收。
4. 总线置零和设置 Node ID 当前仍返回 Abort。
5. 相电流采样量程约 `±1650 mA`，硬件 OCP 为 `2500 mA`，中间存在不可观测区。
6. 1 号板的 RS485 发送链路曾出现间歇性异常，U5 和 A/B 网络仍需硬件复核。
7. 上位机如果加载旧固件保存的 EEPROM 参数，应重新读取 Max Iq 和 Max Speed 进行确认。
