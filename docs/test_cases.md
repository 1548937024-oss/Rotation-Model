# 电机模组串口上位机 软件测试用例

测试对象：上位机（main 分支，含 MSG_Control1 / MSG_GroupControl1、周期发送、2000000 波特率）
通讯协议：电机模组串口通讯协议 V1.2
测试硬件：USB 转 TTL（3.3V，支持 2M bps）+ 集成驱动器（Node ID 1~5）

```powershell
python -m unittest discover -s tests -v
```

## 二、需实机实测（需要你连接真实驱动器反馈）

### B 组：串口与链路

| ID | 用例 | 操作步骤 | 预期结果 |
|----|------|---------|---------|
| B01 | COM 口识别 | 插入 USB 转 TTL，点击“刷新” | 端口下拉出现对应 COM 口 |已通过 |
| B02 | 2000000 连接 | 选 COM 口、波特率 2000000，点“连接” | 状态变“已连接”，无超时报错 |已通过 |
| B03 | 2M 链路稳定性 | 连续自动查询 5 分钟 | 无周期性超时/丢帧，日志无 CRC 错误 |失败，部分周期里没有周期单控报文，详见issues
| B04 | 拔线重连 | 运行中断开 USB，重新插入再连接 | 可恢复连接，无需重启上位机 |失败，显示状态查询失败；

### C 组：单节点控制

| ID | 用例 | 操作步骤 | 预期结果 |
|----|------|---------|---------|
| C01 | 使能/下使能 | 单节点勾选“电机使能”，发送一次 | 状态表“使能”变已使能，电机保持静止 |
| C02 | 位置模式 | 位置模式，目标位置 1000，发送 | 电机转到目标位置，实际位置≈目标 |
| C03 | 速度模式 | 速度模式，目标速度 30%，发送 | 电机按约 30% 额定转速运行 |
| C04 | 目标 Iq 限制 | 设 Iq=20%，观察电流反馈 | 状态 Iq≈20%，不超限 |
| C05 | 参数钳制 | 输入越界位置/速度/Iq | 界面自动限制到 0~65535 / ±100 |
| C06 | 紧急下使能 | 运行中点击“立即下使能” | 电机立即停止，状态“未使能” |

### D 组：多节点控制（最多 5 个从机）

| ID | 用例 | 操作步骤 | 预期结果 |
|----|------|---------|---------|
| D01 | 多控发送 | 勾选 Node 1~5，各设相同控制，发送一次 | 5 台电机同时执行指令 |
| D02 | MCP 槽位对应 | Node 1~5 分别设不同位置/速度 | 每台电机按自己槽位指令动作 |
| D03 | 多节点轮询 | 勾选多个节点后开启自动查询 | 状态表逐节点刷新，互不串扰 |
| D04 | 周期发送多节点 | 勾选周期发送 20ms，目标不变 | 电机平稳运行，无周期抖动 |
| D05 | 周期发送频率 | 分别测 10/20/100/1000ms | 电机跟踪稳定，无控制溢出 |

### E 组：服务与参数

| ID | 用例 | 操作步骤 | 预期结果 |
|----|------|---------|---------|
| E01 | 读取 UID | 服务页“读取 UID” | 返回 8 位十六进制 UID |
| E02 | 读写堵转电流/时间 | 读 0x6073-1/-3，改值写入 | 数值一致，生效 |
| E03 | 设置运行模式 | 下使能状态切换模式 | 返回无错误，模式切换 |
| E04 | 设置零位 | 当前位置设为 0 | 位置反馈归零 |
| E05 | 复位故障 | 注入故障后写入 0x6040=0x0080 | 故障清除 |
| E06 | 修改 Node ID | 按 UID 设置新 ID | 新 ID 立即生效，上位机自动切换 |
| E07 | 新 ID 持久化 | 设置后上使能再断电上电 | 新 ID 保持 |
| E08 | 修改波特率 | 写入新波特率，上位机自动切换 | 切换后能收到反馈；失联可断电恢复 |

### F 组：故障与异常

| ID | 用例 | 操作步骤 | 预期结果 |
|----|------|---------|---------|
| F01 | 母线欠压/过压 | 调整供电电压至阈值外 | 状态表显示对应故障码，电机下使能 |
| F02 | 堵转 | 卡住电机转子运行 | 显示“电机堵转”故障码 6 |
| F03 | 缺相/过流/过温 | 按规格书制造对应工况 | 显示对应故障码并停止 |
| F04 | 故障后恢复 | 清除故障后重新使能 | 可恢复运行 |
| F05 | 断开前下使能 | 勾选“断开前下使能”后断开 | 电机先下使能再关闭串口 |

## 三、实测反馈模板

每完成一项，按下面格式反馈，便于修正代码：

```text
日期：
驱动器固件版本 / Node ID：
USB 转 TTL 芯片型号（CH340/CP2102/FTDI/其他）：
COM 口：
测试用例 ID：
结果：通过 / 失败 / 部分通过
现象（日志、报文、电机行为）：
日志或截图文件：
```

优先反馈 B 组（2M 链路）、D 组（多节点/周期发送）、F 组（故障），这三组最能暴露上位机与实机协议的差异。
